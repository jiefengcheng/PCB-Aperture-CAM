# Aperture-Constrained Copper-Layer Modification — starter suite

A synthetic, single-front-copper-layer engineering experiment. Version 0.1, 2026-10-14.
**NOT FOR FABRICATION. No factory process rules are asserted.**

## Start here

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/demo.py
```

Windows PowerShell activation: `.venv\Scripts\Activate.ps1`.

Then open a COPY of `fixtures/before/kicad/coupon.kicad_pro` in KiCad and inspect the board.
Compare it with `fixtures/candidate/kicad/coupon.kicad_pro`.
The supplied KiCad scaffolds are generated, but have NOT been application-tested here.
A save in a newer KiCad may migrate their older 20240108-format serialization.
Keep the original and the migration copy separate, and log the exact installed KiCad version.

Run native exports after installation:

```sh
python scripts/export_kicad.py --case before
python scripts/export_kicad.py --case candidate
```

The script uses isolated work copies, preserves DRC reports (including violation exit code 5),
and explicitly leaves exported-geometry acceptance pending. Read `docs/KICAD_PLAYBOOK.md`.

## What was actually tested

`evidence/internal_geometry_results.json` records ten synthetic case expectations using
Python 3.13.5 and Shapely 2.1.2. The positive candidate passes the internal geometry policy;
six deliberately bad candidates are rejected; the original fails the aperture objective;
unknown aperture role requires review; an excessive required overlap makes fixed-size
rectangular translation infeasible. These are unit/fixture-level checks, not independent
validation of KiCad or of the Gerber writer.

NOT RUN here: KiCad loading, KiCad DRC, independent Gerber parsing, KiCad-export comparisons,
external-project reproductions, schematic parity, physical fabrication or testing.
KiCad was not installed in the execution environment. No public donor boards or libraries
have been silently copied into this bundle. The public-source acquisition list is in
`docs/PUBLIC_ASSETS.md`.

## Fixture and expected operation

All coordinates are mm, KiCad top view (+Y down).
A1: fixed opening center (20,20), size 1.0 x 1.4.
P1: copper pad initially at (20.35,20), size 1.4 x 1.8.
Required copper overlap outside opening: 0.10 per side.
Assumed relative registration uncertainty: +/-0.05 independently in X and Y.
Thus the nominal copper must contain the opening expanded by 0.15 per side.
Minimum different-net clearance: 0.20. Trace width: 0.25 (minimum 0.20).
Maximum pad movement: 0.50. Pad resizing is not permitted.
P1/P2 are N1; P3/P4 are N2. Only P1 and T1/T2/T3 may change.
T4, T5, P2, P3, P4, all apertures and the outline must remain unchanged.

The solver projects the old pad position onto the feasible rectangular interval:
X in [19.95,20.05]. It chooses X=20.05, a 0.30 mm leftward movement.
The aperture and its specified offset do not move. The local 45-degree trace template is
recomputed up to the fixed connection point (20,23). This is not a general autorouter.
The answer is derived from the opening and the policy; no stored 'golden board' is read.

The original exposure is 1.19 mm2 out of 1.40 mm2. The candidate exposure is 1.40 mm2.
Its minimum copper clearance to the other net is 1.55 mm.
These are computed synthetic values, not factory measurements.

## Directory layout

- `reference/`: immutable opening geometry, invented policy, author-supplied net intent.
- `fixtures/`: original, candidate and six deliberately unacceptable candidates.
- `scripts/demo.py`: constructive generator, constrained translation and internal checker.
- `scripts/export_kicad.py`: native command runner; not a Gerber validator.
- `evidence/`: actual internal test results and explicit untested capabilities.
- `docs/`: KiCad procedure, public asset sources and external validation specification.

Each fixture contains `geometry.json`, a KiCad project scaffold, and two small
`reference_gerbers/` files generated by this script. Those Gerbers are explicitly
NOT KiCad exports. They are suitable inputs for testing an independent reader, not evidence
that KiCad plotting or a production export path has passed. They contain only rectangular
flashes and circular-aperture straight strokes. Their Y coordinates are the negative of
KiCad's Y coordinates; this transform is explicit in the generator. Do not compare raw
coordinates across formats without applying the declared transform.

## Scope limitations

There is no automatic aperture-to-pad matching, Gerber-to-native reconstruction, arbitrary
shape editing, global routing, group aperture solver, hole handling, zone refill, solder
paste handling, flex-bend model, impedance model, solder wetting model or manufacturing
approval. A covered-rim geometric rule is not itself a coverlay material/process model.
There is no schematic; net intent is supplied in JSON and in native pad/track assignments.
An IPC-D-356 exported from a candidate is NOT an independent source of intended connectivity.

The physical-contact checker uses polygon intersection and will accept touching boundaries.
The positive fixture deliberately has substantial overlaps at connections. Add minimum-neck
and minimum-contact robustness tests before using arbitrary geometry; do not reinterpret
zero-area boundary contact as a reliable manufacturable joint.

Arc caps use 64 segments per quadrant, an approximation. The comparison EPS is numerical,
not physical. All manufacturing tolerance values are synthetic and must be replaced only
through a reviewed policy revision, never silently relaxed by a repair.
