# Bounded smooth rims for oversized growth pockets

The owner approved the native-reparsed `3020212956` prototype on 2026-11-06.
It adds 19.9986102% of the completed local repair shape and deliberately retains
54.0243% of the original pocket as one smooth opening. This approves that shape
and strategy, not whole-board electrical or manufacturing acceptance.

The strategy is captured from both remedy registries at job creation. A whole
hole may enter this path only when **the sole failed full-fill predicate is the
existing 20% shortage cap**. Source holes, foreign clearance failures, unsupported
local spans and invalid geometry cannot receive this exception. Smaller admitted
holes retain the existing full-fill path.

For existing local carrier area A and allowed fraction f, the total added copper
is bounded by A*f/(1-f). The empty region is inset and rounded, with an area
reservation for the unchanged native file grid. The chosen rim, original pocket,
carrier and intended remaining opening are bound into the existing owner's
metadata. No new per-feature copper material object is introduced.

The budget is frozen once for each pocket. Later radii skip its declared opening;
later land and junction stages cannot consume it. Mandatory prior-positive copper
participates in rim selection. If it cannot fit within the same budget, the run
halts. Three stage workers reconstruct the same decisions and all native final
checks remain required.

The exported file must retain exactly the declared opening within the existing
2 nm contour uncertainty, keep the cumulative added area below the original cap,
and preserve all source-hole and original-owner protections. Undeclared empty
pockets remain failures. The native inventory reports deliberate retained
openings separately; its zero defect count means zero **unplanned** resolvable
empty pockets.

The nominal 0.040 mm floor, 0.0401 mm construction guard, 1 nm file grid, existing
scalar limits, source coverage, actual export/reparse, and corruption controls
are unchanged. The registered 1% allowance is not consumed. Historical failures
remain unchanged. The prior `.DS_Store` custody finding remains
EXPLICIT_UNWAIVED_UNATTRIBUTED. Coverage recovery stays independent.

## Verification cost

Attachment checking now clips background copper to the complete obligation's
bounds plus two file-uncertainty radii before buffering it by one radius. Every
clipping boundary is outside the influence distance of the required extent.
The original whole-board calculation remains the fallback for local rejection
or an unsupported local overlay. No obligation, positive-effect condition,
threshold or negative control is removed.

constructor plus complete check took 323.873 s versus 1256.7 s for the retained
