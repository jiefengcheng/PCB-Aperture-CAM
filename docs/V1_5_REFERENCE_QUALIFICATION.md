# Completion reference qualification and diagnostic boundary

This clarifies the frozen completion matrix; no required input/check is removed. Required R-INTENT remains NOT_ESTABLISHED where native net data are absent. A geometry/preservation subprofile can pass while overall V1.5 electrical validity remains unestablished.

Source-design reference: sexpdata 1.0.2 reads the immutable native file independently of the Gerber reader. All 80 GlowStitch and 64 HALPI2 pad definitions are considered; nominal coordinates, shape/size, layer, pin and declared net are extracted. Blank repeated GlowStitch references require source IDs plus nominal coordinate association, with no global best fit. Pad XY is footprint-local; the serialized pad angle is already the board orientation. All associations and shape discrepancies are retained. Unsupported source pad kinds or ambiguous associations prevent anchor PASS.

Native segments independently supply nominal same-layer physical endpoint continuity. Named pad nets and native tracks/arcs/stored filled zones can justify scoped same-layer electrical pairs. Native arcs derive their center and sweep from three native points, separately from Gerber I/J/G02 interpretation. Stored native zone cut-ins are interpreted through the same explicitly bounded contour geometry helper: this is independent source data, **not an independent numeric engine**. No zone fill, router or native editing is implemented. The same GEOS kernel is used for vector comparisons; analytic fixtures supply independent mathematical checks for the supported semantics.

For GlowStitch, native nets contain only net 0 and blank references. Physical conductor continuity and immutable baseline-separated source-anchored pad relationships may be preserved and challenged, but they do not become electrical-net truth. The bridge challenge tests preservation of nominal physical separation, not a named-net short. HALPI2 has named nets and supports scoped source-justified same-layer net checks. Cross-layer paths, plating, unassigned copper and factory clearance acceptance remain separately NOT_ESTABLISHED. Measured clearance is not a factory pass.

The first two implementation attempts are retained as failed receipts: one rejected a mistaken layer-role mapping for Paste, and one exposed a corruption-generator bug that altered the format header along with coordinates. The generators are corrected to touch coordinate statements only; those failures are not reported as successful intended-fault detection. Subsequent runs use new directories and fresh exports.

Normative format reference: the repository previously held no pinned specification PDF. This task pins Ucamco Gerber Layer Format revision 2026.05 locally under `out/v15_completion/`, recording URL and SHA-256. No KiCad or existing parser dependency is upgraded. Sections 4.9–4.11 govern aperture transforms, contours and blocks. Block definitions do not have a saved graphics-state stack; the end state persists while current point becomes undefined. Legal contours with paired axial cut-ins are interpreted without geometry repair; other intersections are unsupported. The implemented profile limits units to explicit mm, absolute 2.6/4.6 coordinates, non-nested blocks, rotations within ±360°, positive scales no larger than 1, and supported plotting primitives. Larger scale is refused to preserve the fixed approximation budget.

No independent Cursor review or factory approval is claimed. The adopted completion handoff supersedes intermediate stop clauses, so local work continues through regression and end-to-end reporting.
