# T04 component workspace contract

The accepted five-case copper remains the exact reference. These operation-local helpers consolidate repeated preparation inside the existing bounded direct-group caller. They introduce no new growth or clearance policy, public result fields, persisted cache format or full-board activation.

`StripReservations` prepares each immutable constructed strip's original guarded envelope once. Its wider reservation buffer is materialized lazily once when first needed. Each request excludes the same owner, applies the identical envelope predicate, and returns buffers in original strip order. The caller performs the same ordered union, subtraction and protected-core connection recovery. Straight and arc phases receive separate workspaces because their admitted operands differ. These are construction operands, not clearance audits of groups.

`ResidualScene` owns the accepted mutable material mapping. It uses the existing `stage_abi.spatial_queries.SpatialQueries` fixed index with a versioned update overlay. Every accepted replacement, empty result, insertion and deletion goes through the mapping. Candidate discovery remains a sorted AABB query over every nonempty current source. The caller then excludes the source and same-owner contributions using the same rules, and runs the unchanged exact verifier. Rejections do not mutate this accepted scene. Query-result and proof reuse are disabled. Index-capacity failures fall back to the original rebuilt full index, preserving all candidates. The workspace closes before the separately owned native-joint index is built.

Joint field sampling returns constant offsets directly. A reversed varying field may reuse the forward source path's exact GEOS length for the duration of one proposal; reversed path length and approximate numerical length cannot substitute. Native points, tangent frames, cubic evaluation, reach and slope limits, support intersections, verification and joint assembly stay unchanged.

Qualification compares canonical report/proof values with only enumerated timing fields removed, plus exact serialized source-body and bulk-copper equality. It includes first workspace construction, accepted neighbor updates, budget fallback, and complete bounded caller timing from accepted T03. No geometry tolerance substitutes for report or copper parity. The retained status remains `COMPONENT_DIAGNOSTIC; NOT_COMPLETE_T04` with `constructed_groups_audited=0`.
