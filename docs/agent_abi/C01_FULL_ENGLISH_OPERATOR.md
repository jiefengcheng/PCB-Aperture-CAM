# Full C01 through an ordinary-English operator

The bounded request is: “Please reproduce C01 through T01, export separate
KiCad and Gerber files, and show and check them side by side.” A project-configured
agent selects the adopted C01 contract, not a newly invented T01 policy. The
human supplies no source paths, object IDs, crop coordinates, hashes, commands
or audit JSON. Other crops/policies are outside this route.

## Setup and operator interface

Start the project-native macOS runner once for a fresh execution:

```sh
.venv/bin/python -B tools/start_c01_full_operator.py
```

This publishes a fresh descriptor and active binding under
`out/operator_routes/c01_full/current.json`, preserving previous bindings.
The separate render-only route and its active pointer are retained. No MCP,
network listener, installed service, dependency change or global configuration
is required. The native execution environment remains a setup requirement.

AGENTS.md teaches the stable operator interface once:

```sh
python3 tools/pcb_c01_full_operator.py start
python3 tools/pcb_c01_full_operator.py review "one observation"
```

The first call runs exactly one slice. Each review retains the full agent note,
rechecks the original native receipt, binds the note and all observed facts to
the unchanged native audit fields, then runs only the next permitted slice.
Eighteen separate observations are mandatory. No full-workflow loop or automatic
observation approval is exposed to the agent. HALTED latches failures; terminal
delivery returns verified absolute file paths and asks for no further commands.
