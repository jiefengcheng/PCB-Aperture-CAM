# T04 durable parallel catalogues and covered-trace projection

These are internal source/recipe ABIs used by the bounded group caller. They
are not completed-T04, native-export or manufacturing acceptance contracts.
Parallel groups are geometric relationships; a route remains the existing
connected native source identity.

All records live under `out/lacie_work/source_artifacts/`. Paths are selected by
content keys, not by a mutable-route count or a memory budget. Every reader
verifies bindings and compressed payload hashes. New bindings are published
last; incomplete or modified records fail rather than silently changing work.

* `t04_parallel_relationships/`: existing source straight/native-arc relationships,
  imported byte-for-byte or built with the existing algorithm. Complete accepted
  scene, role-table hash, algorithm and kernel version select the directory.
* `t04_parallel_members/`: retained `t04-full-member-parallel-catalogue/1`, including
  full unequal member extents and stable existing group IDs. The current parent
  has 160 straight and 117 native-arc groups. Membership is independent of
  bounded cohorts and growth widths. This parent is not edited by arc extension.
* `t04_trace_coverage/`: independent `t04-stage-entry-covered-traces/1` records,
  evaluated on complete finite stage-entry copper. Fully covered occurrences
  are KEEP with exact geometry and native IDs retained. Partial coverage stays
  eligible; exact trace aliases cannot conceal themselves. Changed covering
  copper changes the scene binding. Covered occurrences are not growth cores
  and remain fixed operands, not clearance exemptions.
* `t04_maximal_arcs/`: derived `t04-maximal-arc-catalogue/1`, bound to the durable
  parent and curve algorithms. Native arcs join only through unambiguous,
  tangent-compatible endpoints at the 1% confidence setting and equal source
  widths. Source polylines are preserved, including endpoint noise. Branches,
  actual tangent corners and category changes end a member.

Curve relationship discovery first tries the existing positive uniform scale
plus translation fit over complete polylines at 1% maximum residual. It must
not first require nearest-point tangents to agree: translated copies can fail
that unrelated criterion. A retained common-window fit is the fallback for
unequal extents. Fit windows are relationship evidence, never treatment cuts or
clearance authority. Secondary template groups can overlap so a valid member
is not orphaned when its anchor is already assigned. Construction claims each
whole member once and treats prior results as fixed dependencies.

The bounded constructor processes straight groups before arc groups. Maximal
arc members use one pair-budget allocation over their whole lengths and zero
transition reserves at native seams. The maintained source-rail enclosure and
triangle-inequality construction prove their clearance without auditing the
constructed contour. Remaining defaults/joints use search and verification.
Covered occurrences cannot receive growth through a shared member: a mixed
covered/exposed chain remains default work instead of being fragmented.

A multi-occurrence arc member currently has one shared construction contour,
with every real native source reference retained in the recipe. This is explicit
in `body_scope=MAXIMAL_MEMBER_SHARED_CONTOUR`. Source-scene publication/export of
these recipe aliases is NOT_QUALIFIED. True straight/arc endpoint conflicts
remain separate obligations; zero internal seam reserves does not establish
smoothness at every route joint or completed stage acceptance.

Evidence: `out/lacie_work/t04_durable_parallel_20261120/` and
`out/lacie_work/t04_maximal_arcs_20261120/`. No full-board growth run or replay was
authorized for these qualifications.


## Additive larger-corner joint treatment

The bounded caller now finishes default growth with `JOINT_CORNER_FILLS`.
Native degree-two endpoint adjacency supplies this work list; maximal-arc
internal seams and covered receiving occurrences are excluded. One fixed scene
index serves every proposal. This phase does not rebuild the grouping catalogue.

For each exposed face, the farther existing corner donates a displacement d.
The receiving side uses the existing cubic field d * (1 - 3t^2 + 2t^3), returning
to zero at the smaller side with zero endpoint derivatives. Faces are independent;
a wider side does not force symmetric widening on the other side. The longest
available half-member span is tried first, then shorter feasible spans under the
existing 0.25 mm/mm correction-slope bound. Native source points remain unchanged.

A source-centerline half-cell supplies solid backing for the taper. This reuses
the existing side-profile construction and avoids enclosing a sliver beneath an
approximate offset rail. Current same-owner copper is subtracted locally before
checking the positive addition. The proposal must remain inside the input face
envelope (the larger corner or an already wider receiver face), and under the
existing 0.11 mm extra-reach guard. Segment-interior width decisions and all
constructed group operands remain byte-identical. This is a local joined-corner
envelope, not a new uniform segment growth factor.

Only new joint copper passes the maintained foreign-copper clearance predicate,
with its unchanged checking margin. Protected pin domains defer proposals. A
rejection keeps the old copper and remains explicit. Accepted fills are separate
material operands and have their own shape/recipe/check receipts. No existing
copper is shaved away to manufacture a smooth result.

Legacy equal-end-section requirements can be discharged by a fully accepted
additive joint field: native ends may have different widths while the joining
profile is continuous. The result records `resolved_joint_sites`. This proves a
C1 displacement field, not analytic smoothness of every noisy native boundary.
Unresolved joints still block completed-stage publication. The bounded evidence
is in `out/lacie_work/t04_corner_smoothing_20261120/`.
