## Execution interface

`src/gerber_u05/boundary_prepare.py:supports(rows, paths, entry, revision, covered=..., with_sources=True)` borrows the board-owned shared copper revision. It discovers original contact supports once per route before construction. It builds no source index and reconstructs no owners. A compiled component excludes its own source IDs from external supports; an eligible trace crossing another route still constrains their common original junction. The default `with_sources=False` retains the geometry-only interface for existing callers.

`src/gerber_u05/boundary_finish.py:run(rows, paths, bodies, original, width_caps, covered=..., supports=..., maximum_transition_angle_degrees=...)` returns `(source_bodies, removal_masks, endpoint_sections, report)`.

- `rows`: authenticated native source metadata, in the existing coordinate frame.
- `paths`: native route to source occurrence IDs. Scheduling routes can split a physical three-way junction; exact native endpoints reconnect them for finishing.
- `bodies`: already admitted per-source copper, including shared native member contours.
- `original`: immutable stage-entry floors, including authenticated preceding large-copper trimming.
- `width_caps`: existing source-relative T04 width caps; this pass cannot increase them.
- `covered`: immutable KEEP contributions. Aliases retain their identities and floors.
- `supports`: prepared original contact copper, preferably indexed by source identity. This is an operand, not a new acceptance certificate.
- `places`: optional bounded engineering selection `(x, y, radius)`; never a viewer action.

The constructor compiles the endpoint graph and maximal same-width chains once. Ordinary occurrence seams do not terminate a transition. Three-way junction mouths and fixed contact footprints retain nominal copper. Two passes over own-skin width budgets produce a slope-bounded minorant. Piecewise cubic fields have zero derivatives at knots and preserve native paths. Short sections receive less optional width. An incompatible section can withdraw its optional growth entirely; `withdrawn_growth` records this explicitly.

All arms use a common component reference. Only `admitted minus reference minus original/fixed copper` can be removed. The actual finished contour and the assembled per-source contours are checked for remaining additional shoulders. Original corners remain original geometry. A partly improved outline is not qualified. `UNRESOLVED`, new pockets, failed original/subset scope, source contacts or final endpoint obligations stop publication; do not loosen the angle or remove source copper to make a test pass.

`group_components.py` integrates this phase before final existing functional checks. Its profile-derived endpoint obligations supersede only affected optional sections, with prior sections archived. Existing connection, pocket and assembled-board checks remain. `group_board_job.checked` rejects unresolved transitions and failed final endpoint sections.
