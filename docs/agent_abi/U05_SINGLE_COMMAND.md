# U05: verified U04 plus fresh T05

U05 continues an explicit completed U04 result. It verifies its final receipt,
checkpoint, every retained native attempt and machine proof, final artifact
hashes and complete input/source bindings. The U04 prefix is RETAINED_VERIFIED,
not reexecuted or relabelled fresh. A separate U05 job contains every new write.

```sh
tools/Run_U05_Board.command --u04-job "/absolute/completed/U04/job"
```

This Terminal route owns its processes. No pre-opened app, MCP, global settings,
network or installation is needed. Raw-directory U05 and a Local Code embedded
launcher route are not qualified by this retained-continuation interface.
An ordinary-English request to Codex is: “Finish U05 by applying T05 to this
explicit completed U04 job, keeping the predecessor unchanged; return audited
native KiCad/Gerber exports without rendering.”

There are 14 new gates: complete retained-U04 verification; eight T05 gates;
five actual native write/reread, export/reparse and corruption-control gates.
Each gate has a distinct native receipt and deterministic machine proof, freshly
re-evaluated before advancement. Zero human/agent observations are recorded.
The two complete evaluations run concurrently in separate native processes.
Their canonical proofs must match exactly; both process identities, output
hashes and exit codes are retained before the gate advances.
No human or independent review is invented by the pending-review-status gate.

T05 uses the existing land-sized additive spindle kernel: four fixed scales
1, .75, .5, .25; barrier gap .02011 mm; construction guard .02010 mm; hard floor
.02000 mm; 64 buffer quadrants; 1e-12 mm² comparison epsilon and 1e-8 mm² visible
addition minimum. All predecessor sources remain fixed. No rerouting, source
width change, ordinary land edit, neck-down or inferred net intent is allowed.

Admission uses actual saved U04 native geometry and original source contacts.
Without a reference profile the legacy route retains complete-path/window crop
admission. For the adopted C03 restoration, pass the explicit reference below.
Its source-bound local junction views are independent of T04 width eligibility;
full native parents remain context, and additions alone must fit writable space.
All other source copper stays foreign context.
Circle aliases require identical original/current geometry. Covered-land tests
exclude only verified aliases. Inclusive rectangles use original member supports
for original contacts; their filled gaps cannot invent an original attachment.

Every bounded attempt, including KEEP, is reconstructed. Direct patch replay and
all final simultaneous finite-copper checks remain mandatory. Source preparation
and replay reuse are operation-local, with full operand/context hash validation.
Cached geometry is reused only after its exact artifact bytes are read and
SHA-256 checked again. Prepared-plan reuse also rechecks every read operand,
input receipt and complete context. Artifact bytes are never cached. Atomic
no-follow file opens retain kind, regular-file, symlink and corruption guards.
Native exports append qualified contour pieces and preserve all U04 native nodes.
Every resolvable 1 nm grid component/hole remains accounted for. Fresh nine-layer
before/candidate Gerbers are reparsed; before plots must correspond to retained
U04 candidate plots. Every new contour is matched, all old F.Cu atoms and eight
other layers remain protected, and actual new Gerber additions undergo hard-gap,
source-owner, connectivity and bounded-window checks.

Actual connectivity uses the direct plotted owner-plus-contour union. The
unchanged delta-consistency check separately compares that physical union with
owner plus the new-copper delta. This avoids topology artifacts caused by
subtracting and then re-adding existing copper; it supplies no connectivity,
clearance or area-tolerance exemption.

Failures halt with FAIL and subsequent NOT_RUN; they are never resumed/resealed.
The same predecessor and same failed implementation cannot retry. Engineering
corrections require a fresh job and preserve the failure. All outputs, scratch,
logs, cache and tests use out/lacie_work; no internal fallback. No rendering,
commit, push, publication or acceptance promotion is implied. Owner PENDING_USER;
independent NOT_RUN: CHANNEL_UNAVAILABLE; electrical/manufacturing NOT_ESTABLISHED.

next to each qualified addition, clipped to its window. Its depth is twice the
existing maximum native contour/circle tolerance. This changes no geometric

against the full fresh U04 before-plot union and must retain visible area,
