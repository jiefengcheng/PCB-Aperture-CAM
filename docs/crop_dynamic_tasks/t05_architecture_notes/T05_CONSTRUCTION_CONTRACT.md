# T05 implemented spindle-stage contract

Internal family: `land-sized-additive-spindle/1`. Existing accepted outputs stay frozen. This describes implemented behavior and its limits, not an ABI or new authorization.

## Admission is external to the pure stage

A crop adapter must establish original positive-area source contact and current contact between each trace and admitted land, exact source IDs/aliases, original/current geometry hashes, nominal width and immutable route lineage. Supported C02 land operands are filled circles, actual rectangles and the already accepted inclusive rectangles. Physically connected copper is not proof of electrical intent. Do not manufacture owner membership from a shared component label.

Fully covered land operands are skipped with actual coverage evidence. Previously owner-identified fixed bulk contributors remain fixed. C01 branch/mixed components remain outside the qualified local chain construction; the crop adapter records them rather than treating a polygon union as route intent.

## Fixed numerical policy

| Field | Current value | Meaning |
|---|---|---|
| `barrier_gap_mm` | 0.02011 | Conservative buffer removed only from proposed new copper |
| `construction_gap_mm` | 0.02010 | Required exact added-to-foreign distance in final checks |
| `hard_gap_mm` | 0.02000 | Documented experimental floor; construction uses the stricter value |
| `area_epsilon_mm2` | 1e-12 | Boolean area comparison bound, not a distance waiver |
| `minimum_visible_addition_mm2` | 1e-8 | Small additions below this are not counted as grown |
| `buffer_quad_segs` | 64 | Buffer tessellation setting; not an independent analytic curve-error proof |
| `window_land_radii` | 2 | Window extends this many common base radii beyond the admitted land shapes, clipped to the crop |
| `radius_scales` | 1, 0.75, 0.5, 0.25 | Four deterministic proposals; no unbounded search |

The common base radius is the smallest half-minimum-bounding-dimension among the admitted current lands. Context preparation unions the qualified trace and lands, and constructs the window before candidate fitting. Values are version-fixed: a changed contract rejects until a separately named family is qualified. New profiles must not silently mutate the constants of this family.

The 1.5× T04 nominal trace-width cap is not the local T05 spindle-flare bound. T05 adds junction copper sized from the land, while preserving all original nominal trace parts/routes. The earlier short-taper operator has a separate 1.5× local flare contract; it is not the selected broad spindle family.

## Construction, checks and outcome

1. Form a connected qualified owner; a disconnected/malformed owner rejects.
2. Compute a rolling-disc closing at the selected land-radius scale. Extract only added copper and intersect it with the fixed local window.
3. Remove buffered foreign-copper barriers from that optional addition. Never clip, narrow, trim or otherwise modify the original owner or predecessor.
4. Re-union owner and addition. Require a valid connected polygon, owner preservation, correct delta composition, window containment and required added-to-foreign copper distance.
5. Keep the first passing positive addition in the declared four-proposal order; otherwise retain the predecessor and every rejection/zero-growth reason.
6. Repeat every accepted patch check against all other final additions, including later ones.
7. Union additions with the original cumulative predecessor, in the established order. Retain the original source parts and before scene unchanged.

A whole foreign primitive may be exempted only when its geometry is exactly contained by the explicit qualified owner union. Partial coverage is not an exemption. The checker reports each internal witness or measured foreign gap. Same-net and same-component strings do not affect this decision.

Added-copper clearance is not a certification or repair of every inherited gap. Positive-area source contacts and connected polygons do not independently prove net intent, continuous neck width, impedance, mechanical robustness or manufacturing feasibility. The broader spindle checker does not inherit the short-taper family's 17 measured stations or eroded witness. Those would require separate qualification before any stronger claim.

Malformed/disconnected candidates are rejected without silently deleting detached proposed islands or changing original geometry. Failed growth is not a reason to reduce the clearance guard or edit frozen lands. KEEP/no-visible-addition is separate from successful growth; unresolved admission is separate from both.

## Evidence boundary

Every meaningful run retains bound predecessor, per-source source contributions, window/owner/patch hashes, all attempted radii, exact failure operands, final simultaneous checks, cumulative output, actual addition and same-frame full/local visuals. Source-bound replay, package integrity, owner acceptance and independent review are separate status dimensions.

Source-derived case adapters and stored snapshots remain local implementation until separately exposed/qualified. No T05 agent functions or T02 agent functions are registered by this consolidation. No C03 construction starts from this document.
