# T04 architecture and agent boundary

T04 owns **uniform complete-trace width growth**, independently of T02 rectangle growth and T05 junction blending. It consumes an explicit qualified current scene. No source route, land or predecessor is silently edited by admission.

## Module responsibilities

| Layer | Actual module/symbol | Responsibility |
|---|---|---|
| Prepared source scene | `src/trace_first_scene.py:load_scene` | Native original/current contributions and exact replacement custody; current adapter supports declared T01/T04/T02 stages |
| Group model | `src/trace_width_stage.py:validate_width_partition`, `SourceWidthStage` | Complete source-disjoint trace partition, exactly one cohort per trace, protected-source exclusion, finite common factors; deterministic source-family construction |
| Geometry family | `src/source_offset_width.py:construct_source_offset_width` | Original finite source stroke authority, nominal width offset and separate conservative checking envelope |
| Search | `src/bounded_width_solver.py:solve_width_scales` | Stable-order ceiling-first bounded search, one common factor per group/singleton, maximum1.5; coordinate-wise rather than global optimality |
| Resume | `src/resumed_width_solver.py:solve_resumed_width_scales` | Fresh checking of hints/upper brackets; stale saved PASS cannot substitute for execution |
| Verifier | `src/prepared_width_scene.py:PreparedWidthScene`, `src/trace_width_clearance.py` | Simultaneous finite copper-surface growth checks, original local attachment ports, original-source visibility, fixed-neighbor constraints |
| Filesystem adapter | `tools/trace_first_width_stage.py:run_width_stage` | Input/definition/group binding, finite evaluation budget, exact source parts, nominal/envelope final checks, evidence and same-frame rendering |
| Orchestration | `src/trace_first_pipeline.py`, `tools/run_trace_first_pipeline.py` | Sequence/custody/frozen guards; not the width algorithm, not an agent ABI |

The extracted pure group model has no filesystem, UI, global scene, publication or T02/T05 dependency. Each complete trace receives one factor over its full route; immediate parallel members share a factor. A singleton is a group of one. Fully covered contributors and fixed bulk sources are classified before admission and retained as dispositions. Overlapping source parts must be normalized upstream: the model rejects duplicate memberships rather than widening one source twice. Display expansion is the union of each operation's contributions minus the predecessor once, while exact per-source parts remain available for replay.

## Scope and invariants

- Scale1 means unchanged, never repair inherited gaps. Supported growth factors are1..1.5 inclusive. No narrowing, rerouting, pad enlargement or junction flare construction.
- Route centers/segments/arcs and nominal source semantics remain fixed. Clearance uses finite copper surfaces, never route-reference distance as its substitute.
- Fixed lands and all unrelated contributions remain byte-identical. The numerical policy is the bound `TraceWidthContract`:0.02000mm documented floor,0.02010mm construction target and0.02002mm original-port buffer; no unbound universal default for another source family.
- Nominal geometry and conservative checking envelopes are different artifacts. Check both complete simultaneous scenes; do not export envelopes as intended copper.
- Source/group/path/role discovery is external admission, not proved by a group label. Mixed widths, branches or unsupported source semantics require explicit qualification or rejection.
- Fixed-scale source reconstruction is a regression mode, not fresh optimization and not a new maximum proof.

## Current limits before arbitrary stage composition

The pure width model is reusable, but the current filesystem adapter still reads T01-pinned paths and the no-route-change trace-first profile. A T03 route-changing result, T05-blended scene or different source family must be admitted by a separately qualified scene adapter; merely substituting filenames is invalid. General stage permutations are proposed in [the composition contract](../AGENT_STAGE_COMPOSITION.md), not already supported by every runner.

The active pipeline currently integrates T03's checked no-change branch. The preserved bounded route-generator work has not been promoted to a general width-stage input adapter. No larger-region experiment or accepted-result rewrite is performed by this consolidation.

See [the standalone T04 ABI design](T04_AGENT_ABI_PROPOSAL.md). Geometry functions are implemented; agent operations remain design-only.
