# T07 — Deliver the full-crop replay and closure
> **FUTURE PLANNING ONLY — NOT AUTHORIZED by the current T01 handoff. Requires separate owner approval after review of T01 results.**


**Operation stages:** delivery  
**Prerequisite:** T06  
**Autonomy:** Implement, verify, record, and continue within the mandate. No routine human-review gate.


## Objective
Give the owner one reproducible, inspectable demonstration of the requested neighborhood and explain what the implementation achieved.

## Implementation
Extend the existing workbench rather than starting another viewer. Default to the full source-coordinate crop V with synchronized ORG / generated candidate / EDIT. Use actual retained stage snapshots. Every stage selector must retain the correct scene revision, displayed metrics and event-time status under zoom, pan, layer toggles and feature selection.

Show original eligible/kept/unsupported inventory; nominal and accepted contours; already-enlarged neighbors; protected cores; fixed ports and reserved corridors; path/width/junction changes; and final exported residuals. Allow detail inspection without replacing the main crop.

Add one readable decision explanation, for example: “The later shape could not retain its nominal round outline at the declared gap to this already enlarged neighbor, so optional growth was reduced on this side.” Bind it to the actual event; do not use a stock explanation for unrelated decisions.

Expose task execution, technical validity, visible operation, target fit and scope limitations as separate fields. Recorded replay is not live repair. The image reference is not vector ground truth. A/B/C may appear only in a historical/regression section, not as the showcase.

## Verify
- Source/target/candidate roles and scene/event identities remain correct.
- Three genuine current-neighbor adaptation events are navigable if achieved; otherwise the demo objective remains unmet.
- Published geometry derives from the actual scene/export, not an artist's illustration or target substitution.
- Viewport, Q exclusions, inventory denominator, no-op stages and failures remain visible.
- Reuse existing binding/integrity checks, adding only the new stage/state assertions. Do not create thousands of reports or reopen the accepted old publication.
- Check the available target browser/localhost path; state any unavailable browser or file-launch coverage without manufacturing a PASS.

## Final deliverables
One reproduction command using local project conventions; task ledger; frozen experiment contract/policy; source-only prediction/construction receipts; real exports and checks; compact metrics; stage scenes; complete visual case; and a short decision.

The final message leads with:

1. Did the candidate visibly transform the broad requested neighborhood?
2. Were final technical constraints and export checks satisfied?
3. Did the directional-fit objective pass on the qualified domain, and how much of the crop was qualified?
4. What operations or areas remain unchanged/unsupported, and why?

Then report commits/tests/evidence preservation, not the reverse. Local completion is not factory acceptance or permission to advance automatically into another feature stage. Stop at this integrated endpoint with exact remaining issues.
