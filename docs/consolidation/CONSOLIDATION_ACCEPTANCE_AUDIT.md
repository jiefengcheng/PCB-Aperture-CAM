## Invariants used by the audit

- The frozen V1/V1.5 contracts, source assets and original decisions remain
  authoritative. Original aggregate V1.5 and GlowStitch electrical intent remain
  NOT_ESTABLISHED. Neither public native inventory nor graph adjacency changes
  those decisions.
- The approved executor remains the single synthetic MovePadWithConnections
  family. Native context and indexes neither generate acceptance nor grant write
  permission. HALPI2/GlowStitch remain read-only context/regression assets.
- Original source bytes and source locators are retained. A UUID is metadata,
  not global identity. Object occurrences use source digest and byte span,
  scoped by catalog revision. Materialization VIDs/tags remain local.
- Query completeness describes its declared source/layer/geometry scope.
  Unsupported geometry, unavailable indexes, missing intent, cancellation and
  truncation cannot justify no-short or no-obstacle acceptance.
- Directory publication and SQLite transactions establish the documented
  application consistency boundary. Power-loss durability and shared-core
  concurrent snapshot guarantees are not established.
- Cursor review remains NOT_RUN: CHANNEL_UNAVAILABLE. A frozen review packet
  may be produced; a relay or another reviewer is not authenticated Cursor review.

## Required component decisions

The final matrix must separately decide the immutable artifact catalog,
SQLite identity/range access, native libspatialindex Rtree candidates, GEOS exact
predicates, gfs typed graph reads and unavailable custom B-tree/R-tree sources.
ADOPT, KEEP_REFERENCE, SHADOW_ONLY and DEFER have distinct meanings. A missing
custom native implementation is an explicit integration gap, never a mocked PASS.
